# Changelog

## Unreleased

- Added all accepted version 1 Polars table contracts and architecture invariants.
- Added the Slice 1 `Study` substrate over the local editable DataFolio 2 API.
- Added immutable universe and feature-block registration, ordered feature
  selections, scopes, preview/keep, commit history, typed config hashes, lineage,
  and validation.
- Added fresh-process replay, atomic rollback, immutability, corruption detection,
  and contract coverage.
- Added Slice 2 chained raw/scaled feature spaces with independent fit and
  application scopes, persisted missingness reports and sklearn fitted state.
- Added PCA and scaled-passthrough representations, structural revision pointers,
  deterministic replay, and component-manifest validation.
- Added Slice 3's modular, owned fauxnograph implementation and replaceable
  generator protocol, content-addressed clustering runs, reusable candidate cuts,
  optional hierarchy/boundary evidence, revision comparison, and validation.
- Preserved sparse fauxnograph consensus and per-run labels/metadata, with
  configurable Jaccard neighbor weighting, opportunity normalization, and a
  hierarchy-free native-cut path for larger scopes.
- Added quadratic hierarchy preflight estimates, linear-time hierarchy-level
  construction, safe structural run summaries, non-deterministic clustering
  defaults, trusted-model validation opt-in, and clustering reuse coverage.
- Added Slice 4's append-only decision ledger with linear review branches,
  rationale/evidence provenance, strict action payloads, and retained large cell
  targets for merge, split, exclusion, ambiguity, assignment, and related review
  actions.
- Added immutable hierarchical taxonomy versions, rich `IntEnum` bindings, and
  independently versioned assignment sets with manual, feature-based, and
  propagated provenance plus feature-space-relative coverage.
- Added first-class KNN propagation runs with explicit fit/application scopes,
  retained models, per-cell predictions, neighborhood purity and coverage, safe
  default validation, and trusted deterministic replay.
- Enforced same-branch decision ancestry during both append and validation, and
  restored the documented line and branch coverage gates with rejection-path
  tests for Slice 4 contracts.
- Added Slice 5's fixed-schema cells, embedding, feature-profile, stability,
  comparison, taxonomy, history, and release-readiness Polars projections without
  introducing a view class hierarchy or query DSL.
- Added a thin matplotlib-compatible embedding adapter and deterministic,
  self-describing JSON view components with schema, contract, and row hashes.
- Verified the same embedding projection across plotting, serialization,
  fresh-process reopen, and the algorithm-independent candidate seam.
- Added Slice 6 named annotation releases pairing independently versioned
  assignments and taxonomies with an exact source revision.
- Added checksummed release manifests containing copied taxonomy, assignments,
  decision lineage, a quality summary, a resolved language-neutral recipe, a
  replay script, and generated rich-enum source.
- Added fresh-process release loading and validation that avoids estimator and
  generator deserialization, plus a thin Trajan adapter over the release contract
  and Trajan's public annotation-registration methods.
- Enforced that every released assignment originates from the source revision or
  its ancestry, preventing unrelated superset revisions from lending a misleading
  recipe to an assignment set.
- Strengthened whole-study validation to require every committed foreign-key
  target, and pinned hierarchy-node alignment across the generator seam.
- Added commit-head registry caching and distinct-ID provenance checks so large
  assignment sets do not repeatedly reload and revalidate entire registries.
- Centralized software-version and author metadata, canonical feature-column
  naming, configuration JSON imports, and clustering compatibility exports.
- Added concise `TaxonDefinition` and `taxonomy_table()` constructors so callers
  provide biological content while CellPax fills persisted schema boilerplate.
